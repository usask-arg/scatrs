# scatrs

Fast, linearized, rigorously validated single-scattering calculations: Lorenz–Mie, layered
spheres and axisymmetric T-matrix, with a Python interface. The name reads as both
"scatterers" and "scat-rs".

**Status:** pre-alpha. Phase 1a: Lorenz–Mie scattering by homogeneous spheres, with
closed-form derivatives and a validated, CI-enforced accuracy. Layered spheres, the T-matrix,
size distributions and Greek coefficients are still to come.
