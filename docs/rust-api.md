# Rust API

The Python package is a thin layer over the Rust crate `scatrs`, which can also be used
directly. Its API reference is generated by rustdoc from the sources, with every example
compiled and run as a test:

<p><a href="rustdoc/scatrs/index.html"><strong>Open the Rust API reference →</strong></a></p>

The crate is not yet on crates.io, so it is not on docs.rs either; {doc}`installation` shows
how to depend on a checkout.

## The crate and the Python package

| Rust | Python | Contents |
|---|---|---|
| {rust}`scatrs::mie` | {mod}`scatrs.mie` | One sphere: coefficients, efficiencies, amplitudes, phase matrix, Greek coefficients and their derivatives. |
| {rust}`scatrs::ensemble` | {mod}`scatrs.ensemble` | Averages over size distributions, mixtures and batches, with error estimates and derivatives. |
| {rust}`scatrs::special` | {mod}`scatrs.special` | Gauss–Legendre quadrature and Wigner d-functions. |
| {rust}`scatrs::scalar` | | The {rust}`Real <scatrs::scalar::Real>` trait and the double-double and dual-number types. Rust only. |
| {rust}`scatrs::error` | {mod}`scatrs.errors` | The error type, and the exceptions that mirror it. |

The two APIs compute the same things with the same conventions, but differ in shape:

- **Vectorization.** Python functions take arrays and loop over them in Rust. In Rust, a
  {rust}`Mie <scatrs::mie::Mie>` workspace solves one sphere at a time, and the outputs are
  read from the {rust}`MieSolution <scatrs::mie::MieSolution>`, into caller-owned buffers
  where they are arrays.
- **Precision and derivatives.** The Rust kernels are generic over
  {rust}`Real <scatrs::scalar::Real>`, so they also run in double-double precision and with
  {rust}`Dual <scatrs::scalar::Dual>` numbers, for higher derivatives too. Python returns
  `f64` values with first derivatives.
- **Options.** Keyword arguments in Python are builder methods in Rust, such as
  {rust}`MieOptions::with_n_max <scatrs::mie::MieOptions::with_n_max>` and
  {rust}`EnsembleOptions::with_rtol <scatrs::ensemble::EnsembleOptions::with_rtol>`.

The rustdoc is the authoritative statement of each function's accuracy contract and of its
behaviour at the edges of its domain; the theory pages summarise it.
