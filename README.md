# scatrs

Fast, linearized, rigorously validated single-scattering calculations: Lorenz–Mie, layered
spheres and axisymmetric T-matrix, with a Python interface. The name reads as both
"scatterers" and "scat-rs".

**Status:** pre-alpha. Lorenz–Mie scattering by homogeneous spheres, with closed-form
derivatives and a validated, CI-enforced accuracy, including the phase matrix and exact Greek
coefficients; size distributions and mixtures of spheres, with error estimates and
derivatives. Layered spheres and the T-matrix are not yet available.
